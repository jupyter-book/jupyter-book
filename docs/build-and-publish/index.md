## Build workflow

1. Write content in MyST Markdown or Jupyter Notebooks
2. Build to your desired format (website, PDF, Word, etc.)
3. Preview locally
4. Deploy to a hosting platform

## Other static export formats

Beyond websites and PDFs, MyST can export your content to several other formats:

- [Word documents (`.docx`)](xref:guide/creating-word-documents) - Export to `.docx` for collaborators who use Word
- [JATS XML](xref:guide/creating-jats-xml) - Journal Article Tag Suite XML for scholarly publishing
- [`CITATION.cff`](xref:guide/creating-citation-cff) - Generate a citation file from your project metadata

See [](xref:guide/documents-exports) for a complete overview of MyST's export pipeline.
